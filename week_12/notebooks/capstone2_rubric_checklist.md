## ⚠️ COMMON MISTAKES TO AVOID

1. **Choosing too complex a problem** → Keep it manageable
2. **Using toy datasets** → Must use real, substantial data
3. **No train-test split** → Always validate properly
4. **Data leakage** → Fit preprocessing only on training data
5. **No model comparison** → Try multiple approaches
6. **Poor visualizations** → Label everything clearly
7. **Going over time** → Practice presentation timing
8. **Missing deliverables** → Check submission checklist
9. **Starting too late** → Begin this week!
10. **Not citing data sources** → Always cite where data came from
