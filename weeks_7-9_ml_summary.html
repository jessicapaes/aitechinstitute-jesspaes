ML Foundations & Evaluation

Building Your First Models

🤖ML Basics

  • Classification: Predict categories (spam/not spam)
  • Regression: Predict numbers (house prices)
  • Train/Test Split: NEVER test on training data!
  • Stratified Split: Keep class balance
Split: 80% train / 20% test

📊Classification Metrics

  • Accuracy: Overall correctness
  • Precision: Of positives predicted, how many correct?
  • Recall: Of actual positives, how many found?
  • F1-Score: Balance of precision & recall
  • ROC-AUC: Overall discrimination ability

📉Regression Metrics

  • MAE: Average absolute error
  • RMSE: Average error (penalizes big mistakes)
  • R²: Variance explained (0-100%)
R² = 1.0 → Perfect
R² = 0.0 → No better than mean
R² < 0.0 → Something's wrong!

🔄Cross-Validation

The Problem: Single split results vary based on luck

The Solution: K-Fold CV - Test on multiple splits and average

5-Fold CV: Split into 5 parts
Train 5 times, each time use different part as test
Report: Mean ± Std Dev

K=5

Most common, good balance

K=10

More robust, slower

Stratified

Always use for classification!

Week 7 Key Takeaways

  • Always split data BEFORE any analysis
  • Use multiple metrics - no single metric tells whole story
  • Match metrics to business goals
  • Use cross-validation for reliable estimates
  • Test set = sacred vault (use only once!)

Linear & Tree-Based Models

Your First ML Algorithms

📈Linear Models: Drawing Lines Through Data

Simple Linear Regression

y = mx + b
  • One feature → one prediction
  • Example: Price from square footage
  • Fast, interpretable

Multiple Linear Regression

y = b₀ + b₁x₁ + b₂x₂ + ... + bₙxₙ
  • Many features → one prediction
  • Coefficients show feature importance
  • Real-world problems

Polynomial Regression

y = b₀ + b₁x + b₂x² + b₃x³
  • Handle curved relationships
  • Adds x², x³ features
  • Watch for overfitting!

Logistic Regression

P(y=1) = 1 / (1 + e^(-z))
  • For classification problems
  • Outputs probability (0 to 1)
  • Fast, interpretable

⚡ Regularization: Preventing Overfitting

Ridge (L2): Shrinks all coefficients → keeps all features
Use when: Many correlated features, want to keep all
Lasso (L1): Sets coefficients to zero → automatic feature selection
Use when: Many features, few are useful, need sparse model
ElasticNet: Combines Ridge + Lasso
Use when: Best of both worlds, many correlated features

🌳Tree-Based Models: Asking Questions

Decision Tree

  • Series of yes/no questions
  • Easy to visualize and interpret
  • No feature scaling needed!
  • ⚠️ Overfits easily
Age > 30?
├─ Yes: Income > 50k?
└─ No: Deny

Random Forest

  • Train 100+ trees, average predictions
  • Much more accurate than single tree
  • Less overfitting
  • Shows feature importance
  • ✅ Safe default choice!

Gradient Boosting

  • Build trees sequentially
  • Each tree fixes previous mistakes
  • Often wins competitions
  • Powerful but needs tuning
  • XGBoost, LightGBM variants
Model Pros Cons Use When
Linear Models Fast, interpretable, good baseline Only linear relationships Need interpretability, simple patterns
Decision Tree Easy to understand, handles non-linear Overfits easily Quick exploration, need interpretability
Random Forest Accurate, robust, no scaling needed Slower, less interpretable Default choice for most problems
Gradient Boosting Very accurate, handles complexity Slower, needs tuning, can overfit Competitions, need best performance

Week 8 Key Takeaways

  • Start with linear models as baseline
  • Use regularization (Ridge/Lasso) to prevent overfitting
  • Scale features for linear models (not needed for trees!)
  • Random Forest is a safe default choice
  • Trees handle non-linear relationships automatically

Time Series & Forecasting

Predicting the Future

📈Time Series Fundamentals

  • Temporal Data: Data points ordered in time
  • Trend: Long-term increase or decrease
  • Seasonality: Regular patterns that repeat
  • Stationarity: Statistical properties constant over time
  • Autocorrelation: Relationship with past values

🔮Forecasting Methods

  • ARIMA: Classical time series model
  • Prophet: Facebook's forecasting tool
  • LSTM: Deep learning for sequences
  • XGBoost: Gradient boosting with time features
  • Exponential Smoothing: Weighted averages

👥Customer Analytics

  • Customer Lifetime Value (CLV): Future value prediction
  • Churn Prediction: Who will leave?
  • Cohort Analysis: Group behavior over time
  • RFM Analysis: Recency, Frequency, Monetary
  • Retention Curves: Track customer retention

📊 Time Series Components

Trend: Overall direction (upward, downward, flat)
Example: Company revenue growing 10% per year
Seasonality: Regular repeating patterns
Example: Retail sales spike every December
Cyclical: Long-term waves (not fixed period)
Example: Economic boom/bust cycles
Residual: Random noise after removing above
Example: Unexpected events, random variations

Week 10 Key Takeaways

  • Time series data requires special handling (temporal order matters!)
  • Always check for stationarity before modeling
  • Use time-based train/test splits (no shuffling!)
  • Prophet is great for business forecasting with seasonality
  • Customer analytics helps predict behavior and optimize retention

Unsupervised Learning & Recommendations

Finding Hidden Patterns

🔍Clustering Algorithms

  • K-Means: Partition data into K clusters
  • Hierarchical: Build cluster tree
  • DBSCAN: Density-based, finds arbitrary shapes
  • Gaussian Mixture: Probabilistic clustering
  • Use Cases: Customer segmentation, anomaly detection

📉Dimensionality Reduction

  • PCA: Principal Component Analysis
  • t-SNE: Visualize high-dimensional data
  • UMAP: Faster alternative to t-SNE
  • Autoencoders: Neural network compression
  • Goal: Reduce features, preserve information

🎯Recommendation Systems

  • Collaborative Filtering: User-item interactions
  • Content-Based: Item features/attributes
  • Matrix Factorization: Latent factors (SVD)
  • Hybrid Systems: Combine multiple approaches
  • Cold Start Problem: New users/items challenge

🎭 Supervised vs Unsupervised Learning

Supervised: Have labels (y) → Learn mapping X → y
Examples: Classification, Regression (Weeks 7-9)
Unsupervised: No labels → Find hidden structure
Examples: Clustering, Dimensionality Reduction (Week 11)
When to use unsupervised:
- Don't have labels
- Explore data structure
- Customer segmentation
- Anomaly detection
- Feature engineering
Algorithm Best For Limitations Key Parameter
K-Means Large datasets, spherical clusters Must specify K, sensitive to outliers n_clusters (K)
DBSCAN Arbitrary shapes, outlier detection Struggles with varying densities eps (neighborhood size)
Hierarchical Dendrograms, don't know K Slow on large datasets linkage method
PCA Linear relationships, visualization Only linear transformations n_components

Week 11 Key Takeaways

  • Unsupervised learning finds patterns without labels
  • Clustering is powerful for customer segmentation
  • Always scale features before clustering (distances matter!)
  • Use elbow method or silhouette score to choose K
  • Recommendation systems combine collaborative + content-based filtering
